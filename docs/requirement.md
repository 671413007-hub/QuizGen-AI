# Requirement Specification - QuizGen AI

## 1. ข้อมูลระบบ
- **ชื่อระบบ:** QuizGen AI – ระบบสร้างข้อสอบอัตโนมัติด้วย AI
- **เป้าหมาย:** ระบบที่รับเนื้อหาบทเรียนภาษาไทยแล้ววิเคราะห์เพื่อสร้างแบบทดสอบพร้อมเฉลย ให้ผู้ใช้ทำและวิเคราะห์จุดอ่อนเพื่อสร้างข้อสอบซ่อมเสริม

## 2. ฟังก์ชันหลัก (Functional Requirements)
1. **Content Input:** ผู้ใช้สามารถนำเข้าเนื้อหาบทเรียนภาษาไทย (ข้อความ)
2. **Quiz Generation Options:**
   - กำหนดจำนวนข้อ (เช่น 5, 10, 15, 20 ข้อ)
   - กำหนดประเภทข้อสอบ (ปรนัย 4 ตัวเลือก, ถูก/ผิด, เติมคำ)
   - เลือกระดับความยาก (ง่าย, ปานกลาง, ยาก)
3. **Interactive Quiz:** ผู้ใช้สามารถทำข้อสอบผ่านหน้าเว็บ พร้อมระบบจับเวลาและบันทึกคำตอบ
4. **Scoring & Feedback:**
   - ตรวจคำตอบและคำนวณคะแนนอัตโนมัติ
   - แสดงเฉลยพร้อมคำอธิบายเหตุผล
5. **Weakness Analysis:** วิเคราะห์หัวข้อที่ผู้ใช้ตอบผิด
6. **Remedial Quiz:** สร้างข้อสอบชุดใหม่ที่เน้นเนื้อหาหรือหัวข้อที่ผู้ใช้ตอบผิดโดยเฉพาะ

## 3. ข้อกำหนดทางเทคนิค (Non-Functional Requirements)
- **UI:** ใช้งานง่ายและดูเป็นระบบจริง สะอาดตา รองรับภาษาไทยสมบูรณ์
- **Platform:** พัฒนาบน Windows และ PowerShell
- **Version Control:** รองรับการจัดเก็บบน GitHub
- **Extensibility:** โครงสร้างระบบต้องเอื้อต่อการเชื่อมต่อ AI for Thai / ThaiLLM ในอนาคต
